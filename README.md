# Gyubeom Jo - Portfolio

A minimal, responsive static portfolio with About, Publications, and Projects pages.
Open index.html in a browser. No installation or build step is required.

## Editing
- Personal information and education: site.js
- Publications and projects: the arrays at the top of site.js
- Layout and appearance: style.css

Publication fields: title, authors, venue, year, url.
Project fields: title, description, tags (an array), url, optional year.
Only add verified work and trusted https links.

The initials beside the profile name are a placeholder for a future profile photo.
All fonts are local system fonts. No external assets or dependencies are required.

Visual reference: https://github.com/Andrei-Stefan20/developer-portfolio-template
This site uses an original static implementation, not the Jekyll template.
